# MailFlare Documentation

Create and manage email aliases on your own domains with Cloudflare Email Routing, from your
browser or as a web app.

## Quick Start

1. **Install the extension.** Download MailFlare for
   [Chrome](https://chromewebstore.google.com/detail/mailflare-email-alias-ext/aomfbgcabccoecaoimicmmkjdmdgcfpi)
   or [Firefox](https://addons.mozilla.org/firefox/addon/mailflare/), or use the
   [web app](https://app.mailflare.cc).
2. **Connect it to Cloudflare.** Either create a Cloudflare API token (see
   [API Token Setup](guides/api-token.md)), and every alias becomes an Email Routing rule; or
   deploy the Mailflare Worker (see [Worker Mode](guides/worker-mode.md)), which keeps your aliases
   in its own database and lets you reply from them.
3. **Manage your aliases.** Create, edit, search, and delete aliases across your domains.
4. **Use the context menu.** Right-click on any page to create an alias for that site and copy it
   to your clipboard.
